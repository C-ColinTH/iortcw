## iortcw: The Combine Edition
> Merging some great features from RealRTCW, and original enhancements.

### Description

**iortcw: The Combine Edition** is a specialized fork of the [ioRTCW](https://github.com/iortcw/iortcw) project. Its primary goal is to integrate gameplay features, quality improvements, and enhancements from the popular [RealRTCW](https://github.com/wolfetplayer/RealRTCW) while maintaining a maximum compatibility and stability as possible.

This branch serves as a middle ground: a feature-combined, highly compatible base for players who want a richer experience than pure RTCW but with a more conservative approach than a full overhaul.

### Compilation and installation

The same as the SP part of **iortcw**.
